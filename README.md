# Odisha Police Constable Mock Test-23 🚓✏️

A premium, interactive, single-file offline **Mock Test HTML Website** designed for **Polai Education Hub** competitive exam aspirants.

---

## 🌟 Key Features

- 📄 **100% Single-File Offline HTML:** Works locally without any backend, database, or internet connection.
- 🌐 **Bilingual Questions (English + Odia):** All 20 Mathematics practice questions from Mock Test-23 with original options and detailed step-by-step explanations.
- 📊 **Testbook-Style Question Palette:** Visual navigation grid with color-coded status badges (*Answered, Not Answered, Marked for Review, Not Visited*).
- ⏱️ **Live Countdown Timer:** 25-minute exam timer with visual warning when time is running low and automatic test submission at 00:00.
- 🎯 **Automated Scoring:**
  - Correct Answer: `+1.0 Mark`
  - Wrong Answer: `-1/3 (-0.33) Mark`
  - Unattempted: `0 Mark`
- 📈 **Result Dashboard:** Score card, accuracy rate, percentage, time taken, performance breakdown, and printable result option.
- 🔍 **Detailed Answer Review:** Review selected vs. correct answers with full explanations in English & Odia.
- 🎵 **Web Audio Sound Effects:** Built-in synthesizer for click sound effects, option selection, start chime, and finish fanfare with Sound ON/OFF toggle.
- 💾 **LocalStorage Auto-Save:** Automatically saves test progress so accidental browser refreshes do not erase answers.
- 📲 **Polai Education Hub Community Links:** Direct social links to YouTube Channel, Telegram Channel, and Telegram Doubt Group.

## 🚀 How to Run Locally

1. Download or clone this repository.
2. Double-click on `index.html` to open it in any web browser (Chrome, Edge, Firefox, Brave, Safari).
3. Click **"START TEST NOW"** to launch the test.

## 🌐 Free Hosting on GitHub Pages

You can host this mock test for free on **GitHub Pages** so students can take the test online from anywhere:

1. Create a new repository on [GitHub](https://github.com/new) (e.g., `odisha-police-mock-test-23`).
2. Upload `index.html` and `README.md` to the repository.
3. Go to **Settings** > **Pages**.
4. Under **Branch**, select `main` (or `master`) and click **Save**.
5. After 1 minute, GitHub will give you a live website link like:  
   `https://<your-username>.github.io/odisha-police-mock-test-23/`
